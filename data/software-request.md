# Software Request Process

Need a new tool or license? Request it through the official channel instead of installing it yourself.

Step 1: check the ServiceDesk software catalog first. Many common tools (IDEs, design apps, PDF editors) are pre-approved and install in one click.

Step 2: if it is not in the catalog, open a "Software request" ticket with the tool name, vendor, cost, and business justification.

Step 3: IT reviews for security and license compliance within 3 business days. Requests under $200 per year are approved by IT directly; larger ones need manager approval too.

Shadow IT is not allowed: installing unapproved software that touches company or customer data is a policy violation and the software will be removed.

Open-source tools: allowed for work use, but check the license with IT first if the tool will be embedded in anything we ship to customers.
