# Phishing Response Guide

Phishing is the most common way attackers get in. If an email looks suspicious, treat it as guilty until proven innocent.

Warning signs: unexpected urgency ("act now"), requests for credentials or payments, slightly misspelled sender addresses, and attachments you did not ask for.

If you receive a phishing email:
1. Do NOT click links, open attachments, or reply.
2. Report it with the "Phish Alert" button in your email client. This quarantines the message and notifies the security team automatically.
3. If you already clicked: disconnect from the network, do not enter any credentials, and call the security team immediately.

The security team triages reported phishes within 2 hours and will tell you whether it was malicious.

Training: everyone completes a 20-minute phishing awareness module each year, plus occasional simulated phishing tests. Failing three simulations in a row triggers a 1:1 coaching session, not punishment.
