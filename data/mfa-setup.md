# MFA Setup Guide

Multi-factor authentication is required for email, VPN, the HR portal, and all admin consoles.

Step 1: install an authenticator app on your phone (we recommend the apps listed in the IT software portal).

Step 2: go to account.northwind.example/security, click "Set up authenticator", and scan the QR code with the app.

Step 3: enter the 6-digit code from the app to confirm. Register a second method (SMS or a hardware key) as backup.

Backup codes: after setup, download your 10 one-time backup codes and store them somewhere safe and offline, for example printed in a locked drawer. Each code works once.

Lost phone: use a backup code to sign in, then contact the ServiceDesk to reset your MFA. Identity is verified via your manager before the reset.

Never approve an MFA prompt you did not trigger. Report unexpected prompts to security immediately.
